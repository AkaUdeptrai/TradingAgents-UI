# Codex repository guidance

`github.md` defines this repository's GitHub workflow. The root `AGENTS.md`
instructs agents to read it; this directory is project documentation, not an
automatic permission grant or a replacement for Codex application settings.

Keep only shared, versioned guidance here. Do not commit personal settings,
credentials, sessions, or local task logs.

Reference: [OpenAI guidance on repository instructions](https://developers.openai.com/cookbook/examples/codex/iterating-development-workflows-with-codex).
